One satirical sentence roasting lawmakers who would regulate AI but cannot convert a file to PDF.

## Entry

> Congress can write a law governing artificial intelligence, but its authors still print the Word file, sign it in pen, and scan it back in upside down to make a PDF.

## How it works

`main.ts` writes that single sentence to `/output/entry.txt`. Run it with:

```sh
node main.ts
```
